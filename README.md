# MetabolicHQ wiki

Coach Bronson's knowledge base for MetabolicHQ, MPT and the coaching business, kept by Claude using Andrej Karpathy's
"LLM Wiki" pattern.

- **Start at [index.md](index.md).**
- How it's maintained: [CLAUDE.md](CLAUDE.md). What changed and open questions: [log.md](log.md).
- Updated nightly from the app repo, the site repo and the backlog.

To browse it in Obsidian, clone the repo and open the folder as a vault; links are plain Markdown and work there and
on GitHub.

To use it in another Claude session, attach this repo; the session reads `CLAUDE.md` and `index.md` first.
